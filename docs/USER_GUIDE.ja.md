# 使い方ガイド

[READMEに戻る](../README.ja.md) · [English](USER_GUIDE.md)

壁紙の割り当て、編集、共有、自動切り替え、自動化の詳しい使い方です。

## 壁紙の割り当てと編集

アプリを起動すると、メニューバーにアイコンが追加されます。

1. メニューバーから **設定** を開く
2. **壁紙** タブで動画・アニメーション画像・プレイリストを追加する
3. ライブラリ上部の **割り当て先** で「デスクトップ」または「ロック画面」を選び、壁紙を割り当てる
4. デスクトップタブでは、スコープを切り替えるとディスプレイ別・Mission Control のデスクトップ別に割り当てできる
5. ロック画面を使う場合は、ロック画面パネルで同期を有効にして **今すぐ設定** を押す
6. **編集** タブで、配置（位置・ズーム）とトリム（カット範囲・ループ開始位置）を調整する

ステータスバーでは、現在のデスクトップ壁紙とロック画面壁紙をそれぞれ確認できます。

画像の壁紙は、編集タブから **シーンエディタを開く** と、別ウィンドウでレイヤー・エフェクト・動きを編集できます。JavaScriptや3Dモデルの仕様は、[スクリプトAPI](SCENE_SCRIPT_API.md)と[3Dモデルガイド](SCENE_3D_MODELS.md)を参照してください。

## 読み込める壁紙

- **動画を壁紙に**: 手元にある動画ファイル（mp4やmovなど）を壁紙として流せます。
- **アニメーション画像**: GIF / APNG / アニメーションWebP を読み込むと動画へ変換され、他の壁紙と同じように再生できます。
- **Web壁紙（実験的機能）**: WebページやYouTube / VimeoのURLを登録して壁紙にできます。設定でオンにすると壁紙タブにセクションが表示されます。

HTMLのフォルダを登録する場合は、[Web壁紙API](WEB_WALLPAPER_API.md)を参照してください。

## 表示先とプレイリスト

- **デスクトップとロック画面を別々に設定**: デスクトップ用とロック画面用で、それぞれ別の動画を割り当てられます（ロック画面同期は macOS 26 以降）。
- **マルチディスプレイ対応**: メイン画面だけ／全ディスプレイの切り替えに加え、画面ごとの割り当てもできます。
- **デスクトップ（Space）ごとの壁紙**: Mission Control のデスクトップごとに別の壁紙を割り当てられます。メニューバーにデスクトップ番号を表示することもできます。
- **プレイリスト**: 複数の動画を登録して順番に再生できます。シャッフルや前／次の操作にも対応しています。
- **スクリーンセーバー**: 設定からインストールすると、デスクトップの動画の壁紙をそのまま macOS のスクリーンセーバーとして再生できます（画面ごとの壁紙・トリム・配置も反映。Web壁紙は非対応）。アプリの起動中は自動でスクリーンセーバーに選ばれ、終了・アンインストールすると元のスクリーンセーバーに戻ります。

## 編集と見やすさ

- **トリム編集（カット／ループ）**: 使いたい部分だけを切り出し、ループ開始位置を別途指定できます（初回だけカット開始位置から流れる＝イントロ）。キーフレームへの吸着、タイムラインのズーム、取り消し／やり直しにも対応。
- **配置編集（Fit Editor）**: 各ディスプレイごとの表示モード、ズーム、オフセットを編集して、画面ごとの見え方を保存できます。
- **切り替えエフェクト**: 壁紙が変わるときにクロスフェード、または黒を挟んで切り替わります（オフ／0.5／1／2秒）。デスクトップの切り替え時と、視差効果を減らす設定がオンのときは効きません。
- **音量調整**: 動画の音量をアプリ内から調整可能です。
- **デスクトップアイコンの表示切替**: システム設定と同様に、デスクトップ上のアイコン表示／非表示を切り替えられます。
- **見やすさの調整**: 壁紙全体を暗くしてアイコンやファイル名を読みやすくしたり、メニューバーを不透明にできます。
- **カーソルのエフェクト**: 動画の壁紙に、マウスの動きに合わせて壁紙が少しずれる視差効果、カーソルの周りだけを明るく見せるスポットライト、カーソルの後ろに光の粒が流れる軌跡（光・キラキラ・泡・雪）、デスクトップをクリックした場所の波紋やはじける光を重ねられます。色はパレットから自由に選べます。編集タブの「エフェクト」で壁紙ごとに設定でき、その設定は書き出しや Store への投稿にも含まれます。権限は不要です。負荷を抑えるため、既定ではほかのアプリを使っている間はマウスの監視ごと止まります。低電力モードやMacが高温のときもオフになり、視差効果・軌跡・クリックは「視差効果を減らす」がオンのときと、バッテリー駆動中に再生の負荷を下げているときもオフになります。Web壁紙では使えません。

## 再生負荷と省電力

- **Macのための最適化設定**:
    - 他のウィンドウが画面を大きく覆った時は、自動で壁紙の再生を一時停止します。
    - 「このアプリを使っている時だけは一時停止しない」といったアプリ・ディスプレイ単位の除外設定も可能です。
    - 画質プリセット、作業プロファイル、フレームレート（30fps / 60fps / 制限なし）、デコードモードを調整できます。
    - バッテリー残量が10%以下になると、自動的に再生の負荷を下げます。
    - バッテリー駆動中の動作を「通常どおり／負荷を下げる（軽量版で再生）／静止画にする」から選べます。電源につなぐとすぐに元へ戻ります。
    - システムの「視差効果を減らす」がオンのときは、壁紙を静止フレームで止めます。

- 他のウィンドウで壁紙が完全に隠れると、自動で再生を一時停止します。
- 覆われた状態が続くと、デコードに使う重いリソースを解放してメモリを節約します
  （再表示するときは静止画から滑らかに再生へ復帰します）。
- macOS の App Nap に対応し、非アクティブ時のCPU起床を抑えます。
- 軽量再生モードでは、負荷の小さいプロキシ動画を生成して省電力に再生します。
- 画質プリセット・作業プロファイル・フレームレート（30 / 60fps）・デコードモードを
  Macの余力に合わせて選べるほか、バッテリー残量が少ないときは自動で画質を下げます。

## ライブラリと共有

- **Store**: 他のユーザーが共有した壁紙を見てダウンロードしたり、自分の壁紙を投稿（審査あり）したりできます。
- **壁紙の共有・エクスポート**: 設定画面から任意の登録済み壁紙を選んで共有できます。選択すると保存先フォルダを指定して、`.lwpkg`（壁紙パッケージ）と元動画（.mov/.mp4）を出力します。エクスポート時はサムネイルやメタデータ（再生位置・配置情報など）も含まれます。
- **パッケージのインポート**: 受け取った`.lwpkg`ファイルはアプリ側からインポート可能で、メタデータに基づいてプレゼンテーション設定やプレイリストを復元します。重複した動画の扱い（置換／中止）も選べます。
- **Storeへの投稿**: Storeへの共有では、保存済みのトリム・フィット設定と一緒に動画を送信し、審査を経て公開されます。「自分の投稿」タブではこのMacから送った投稿の審査状況を確認でき、投稿の取り下げや、他の投稿の通報も行えます。
- **サムネイルキャッシュ**: サムネイルはディスク／メモリでキャッシュされ、高速な一覧表示とプレビューを提供します。
- **ドラッグ&ドロップとファイル操作**: 動画のドラッグ&ドロップ追加、プレイリストへのドラッグ操作、登録動画の名前編集などに対応しています。
- **検索**: 壁紙一覧・プレイリスト・Web壁紙・Storeのカタログは、各リスト上部の検索欄から絞り込めます。
- **不具合の報告**: 設定 › その他 › サポートの「診断情報を書き出す…」で、アプリ・macOS・ディスプレイの情報、設定、直近のログを1つのzipにまとめられます。「不具合を報告…」から GitHub の issue を開いて添付してください（動画ファイルや Web 壁紙の URL は含まれず、ホームフォルダのパスは `~` に置き換わります）。

## 壁紙の自動切り替え

3つの仕組みで壁紙を自動的に選べます。いずれも **壁紙** タブから設定します。

- **外観（ライト／ダーク）**: ライトモード用・ダークモード用の壁紙を選んでおくと、macOSのダークモード切り替えに合わせて共有壁紙が入れ替わります。
- **曜日スケジュール**: 曜日・時間帯・外観条件を組み合わせたルールを作れます。上にあるルールほど優先され、最初に一致したルールが適用されます。22:00〜06:00 のような日またぎの時間帯にも対応。時間帯の始まりと終わりには「日の出」「日の入り」も選べます（「日の入り〜日の出」で夜だけ、など）。場所は既定でタイムゾーンの代表都市（日本なら東京）から推定し、「場所を変更…」で都市名を検索して変えられます。位置情報の許可は不要です。ルールが有効な間に手動で壁紙を選び直した場合は、次の時間帯の境界までその選択が維持されます。
- **集中モード**: 集中モードごとに壁紙を割り当てられます。macOSは集中モードの情報をアプリに公開していないため、通知センターのデータベースを直接読む方式を採っており、**フルディスクアクセス** の許可が必要です（アプリ内に手順の案内があります）。

## 自動化

### グローバルショートカット

設定の **グローバルショートカット** をオンにすると、アプリを前面に出さずに操作できます。初期設定は以下の通りです。

| 操作 | 既定のキー |
| --- | --- |
| 次の壁紙に切り替え | ⌃⌥⌘ ] |
| 前の壁紙に切り替え | ⌃⌥⌘ [ |
| 音声のオン/オフ | ⌃⌥⌘ M |
| デスクトップアイコンの表示/非表示 | ⌃⌥⌘ D |
| 壁紙の一時停止/再開 | ⌃⌥⌘ P |

キーの割り当ては変更できます。システムや他アプリと重複している組み合わせは「無効」として表示されます。

### URLスキーム

`livewallpaper://` のURLを処理するので、ショートカット.appの「URLを開く」、Raycast、AppleScript、`open` コマンドなどから操作できます。

```bash
open "livewallpaper://next"
```

| URL | 動作 |
| --- | --- |
| `livewallpaper://next` / `livewallpaper://previous` | 次／前の壁紙を再生 |
| `livewallpaper://pause` / `livewallpaper://resume` | 壁紙を一時停止／再開（`toggle-pause` で切り替え） |
| `livewallpaper://set?name=Ocean` | 表示名で壁紙を選んで切り替え |
| `livewallpaper://set-playlist?name=作業用` | 表示名でプレイリストを切り替え（`name=all` で「すべての壁紙」） |
| `livewallpaper://audio?on=1` | 音声をオン（`on` を省略するとトグル） |
| `livewallpaper://volume?level=0.3` | 音量を設定（0.0〜1.0） |
| `livewallpaper://desktop-icons?visible=0` | デスクトップアイコンの表示／非表示（省略でトグル） |
| `livewallpaper://playlist?on=1` | プレイリスト再生のオン／オフ（省略でトグル） |
| `livewallpaper://shuffle?on=1` | シャッフルのオン／オフ（省略でトグル） |
| `livewallpaper://refresh` | 再生状態を再評価 |
| `livewallpaper://settings` / `livewallpaper://wallpaper` | 設定／壁紙タブを開く |

名前は大文字小文字と全角／半角を区別せず、完全一致、なければ前方一致で探します。候補が複数ある・見つからない・未知のコマンドのときは何もせず、ビープ音で知らせます。一時停止はアプリを再起動すると解除されます。
