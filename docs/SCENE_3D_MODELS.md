# シーンの3Dモデル

シーンエディターの「＋」→「3Dモデル(glTF)…」で、glTF 2.0 のファイル（`.gltf` と、それが参照するファイル、または `.glb`）をレイヤーとして読み込めます。

## 読み込めるもの

| 内容 | 対応 |
| --- | --- |
| メッシュ | 三角形のみ。点や線は読み飛ばす |
| 頂点 | 位置・法線・接線・UV（`TEXCOORD_0` だけ）・頂点色・`JOINTS_0` / `WEIGHTS_0` |
| 材質 | metallic-roughness（基本色・金属/粗さ・法線マップ・AO・発光）、`alphaMode`（OPAQUE / MASK / BLEND）、`doubleSided`、`KHR_materials_unlit` |
| 画像 | PNG と JPEG（GLB 内、data URI、モデルと同じフォルダかその下のファイル） |
| 動き | スキン（骨）とノードのアニメーション（translation / rotation / scale、LINEAR / STEP / CUBICSPLINE）。読み込み時に 30fps で標本化する |

読み込めないもの: Draco・meshopt の圧縮、KTX2・WebP の画像、sparse accessor、モーフターゲット、`TEXCOORD_1` 以降を使うテクスチャ、カメラとライト（`KHR_lights_punctual`）。`extensionsRequired` に未対応の拡張がある場合と、頂点数が200万を超える場合は、読み込みを断る。

法線のないメッシュは面ごとの法線（フラット）で描く。法線マップがあって接線がないときは、UV から接線を作る。

## 置き方

モデルは画像レイヤーと同じキャンバスに置く。

- 位置・大きさ・回転（キャンバス面内）はレイヤーの配置で決まる。キーフレームとモーションも同じように効く。
- 読み込んだ直後は、キャンバスの中央に、高さか幅の 60% に収まる大きさで置かれる。
- 「向き」は縦軸まわりの回転、「傾き」は横軸まわりの回転、「手前へ」は画面から手前へ出す量（ピクセル）。
- 不透明度と色合いは効く。合成モード・視差の奥行き・カーソルで透かすは効かない。

## 3Dモデルの見え方（シーン全体）

シーンにモデルを1つ読み込むと、「スクリプト」タブに「3Dモデルの見え方」が出る。最後のモデルを消すと、この設定もなくなる。

- **画角**: 0° は遠近なし（平行投影）。それより大きいと遠近が付く。視点を回していなければ、キャンバス面（奥行き0）は平行投影と同じ大きさで写る。
- **視点の左右・上下**: キャンバスの中心を軸に、モデルを見る向きを回す。画像レイヤーは回らない。
- **空からの光・地面からの照り返し**: 全体を照らす光。上を向いた面は空の色、下を向いた面は地面の色で照らされ、映り込みにも使われる。
- **光**: 最大4つ。平行光（太陽）・点光源・スポットライト。点光源とスポットライトは「届く距離」（キャンバスの高さを1とした長さ）で、明るさが 1/4 に落ちる。影を落とせるのは平行光とスポットライトだけ。
- **影を受ける床**: 見えない水平の床で、モデルの影だけを下の絵に落とす。オンにした時点で、一番低いモデルの足元に高さを合わせる。

## 描き方

材質はアプリの描画で描く（glTF の metallic-roughness: GGX・Smith・Schlick・Lambert）。環境マップは使わず、全体を照らす光は空と地面の2色だけで近似する。そのため、磨いた金属は Blender などのプレビューより暗く、映り込みもない。

色の計算はリニアで行い、Khronos PBR Neutral のトーンカーブを通してから sRGB に戻す。

## 書き出し

ロック画面・スクリーンセーバー用のループ動画にも、モデルとアニメーションが入る。アニメーション1回の長さがシーンのループの長さで割り切れないと、ループのつなぎ目でポーズが飛ぶ。「再生の速さ」で合わせる。
